# happy-biscuit
its a fun personal website

This website is a project for Hack Club and is a personal website made for fun
To use it you could just visit the website happybiscuit.vercel.app , but if you want to use it locally you will have to download all the files and run the index.html on localhost.

I used vercel to deploy the site as I am yet to learn git.

The website is a classic scroll animation and includes 3 webpages, home, shop and contact.

some texts use the " dinosaurs are real " font i downloaded online.

the website does have a fallback where if the font is not found it falls back to serif.
